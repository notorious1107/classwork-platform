# 验证记录

最近验证环境：Windows、Node.js 22.17.0，2026 年 10 月 19 日（北京时间）。包含浏览器 GUI 探索与 20 项 Chromium 端到端测试。完整结果以重新运行项目命令的输出为准。

## 已验证

- 前后端 TypeScript 检查，以及可启动的生产构建。
- 开发服务器通过 Vite 代理登录、读取身份和退出；显式保留 Host，使同源来源校验在开发模式也正常工作。
- 16 项后端和数学测试：角色权限、同班与本人数据边界、旧页面身份与 Cookie 账号不一致时拒绝读写、创建学生、登录 / 退出 / 修改密码 / 重置密码、10 / 20 / 50 题发布、三类知识点、名单快照、保存草稿、版本冲突、截止校验、自动批改、空题计错、提交锁定、教师统计、干净数据库初始化与文件数据库重新打开。
- 出题属性测试对三类题各进行 50 批、每批 50 题检查（共 7,500 题），使用独立表达式求值器验证运算优先级、答案、数值范围及单份题目不重复。
- Chromium 桌面完整流程：教师创建学生 → 选择知识点并发布 → 学生自动 / 手动保存 → 刷新和重新进入继续 → 教师查看草稿 → 学生正式提交 → 错题中展示自己的答案与正确答案 → 教师核对得分、人数、平均分 → 退出后重登查看结果。
- Chromium 的 390 × 844 移动尺寸：登录、作业列表、50 道题答题布局无页面横向溢出、模拟断网保存失败并恢复重试、保存后离开再进入。
- 同一账号两个浏览器标签页的草稿版本冲突；旧页面不能静默覆盖新答案。
- 输入后立即退出登录，先保存草稿，再撤销会话；重新登录后可恢复答案。
- GUI 及新增端到端测试覆盖错误登录后重试、角色页面重定向、重复账号、搜索空结果、新学生名单快照、三个题量与混合知识点、0 / 90 / 100 分、取消提交后继续填写、教师错题筛选、已截止草稿只读、修改与重置密码、会话撤销、列表请求失败重试、教师手机页面。
- 异常恢复测试覆盖跨标签页退出、切换到不同账号、在新页重新登录并回原页保存、草稿保存成功但响应丢失、提交成功但响应丢失。共 **20 项** Chromium 端到端测试。
- 真正停止并重启独立后端进程后，账号、登录会话、发布的题目、草稿、正式成绩和教师统计均保留。

浏览器测试使用新建的独立 SQLite 文件，不会更改默认演示数据库。截图和失败追踪输出在 `test-results` 目录，该目录不纳入源码版本。

20 项测试分布：`e2e/classroom.spec.ts` 4 项原主流程，`e2e/forms-and-results.spec.ts` 11 项表单和业务边界，`e2e/recovery.spec.ts` 5 项异常恢复。除 GUI 发布流程本身外，部分测试通过 API 准备数据；截止测试仅在独立测试数据库中预设已过期状态，随后通过页面验证只读行为，不修改实际业务库。

浏览器 GUI 探索与修复证据见 [2026-10-19 验收报告](gui-audit-2026-10-19.md)。GUI 手动操作使用 `3100` 的单独数据库；正常服务保留在 `5173`。

- 未进行真实教师与学生的课堂试用。
- 未用真实手机、平板、另一台电脑或校园局域网连接；移动测试是 Chromium 浏览器尺寸模拟。

- 未配置公网域名、TLS/HTTPS、托管服务器、自动备份、监控或持续部署。
- 未进行大量用户并发、负载、故障注入或独立安全审计；本版本按一个班级、一个后端进程设计。
- 未验证强制关机 / 断电等系统层故障；建议定期停止服务后备份数据库目录。

## 当前明确限制

单班级、一个初始教师；新增学生只参加后续发布的作业；正式提交一次后不可改；截止后不补交；不支持离线同步、作业撤回、编辑已发布题目、人工改分、成绩导出、多班级或公开注册。

Node.js 22.17.0 会对内置 SQLite 打印 ExperimentalWarning，本环境中不会妨碍启动、保存、构建和测试。
